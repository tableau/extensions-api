# M1.1 Task Brief — Catalog hygiene + `used` flag

**Status:** Done  
**Milestone:** M1.1 — between M1 (done) and M2

## Goal

Tighten the Omnisearch field catalog and add a first-pass **`used`** boolean on every indexed field.

1. **Exclude** dashboard action auto-columns from the catalog.
2. **Add** `used: boolean` on `FieldRecord`, computed from downstream references including parameter `source-field`.

## Catalog exclusion rule

**Exclude from `buildFieldCatalog()`:**

```text
type === "group" AND attrs["user:auto-column"] === "sheet_link"
```

**Keep:** sets (`user:ui-builder: "filter-group"`), ordinary groups, columns, calcs, parameters.

**Fixture example:** `[Action (Customer Segment)]` excluded; `[Segment Set]` retained.

---

## `used` semantics

`used === true` when the field is referenced in **any** of:

| # | Signal | Source | M1 status |
|---|--------|--------|-----------|
| 1 | **Downstream dependency** | Calc / set / group formula or definition | Exists (`dependencyGraph`) |
| 2 | **Sheet usage** | Worksheet or dashboard shelf, filter, encoding | Exists (`fieldUsage`) |
| 3 | **Action reference** | Workbook `<actions>` nodes (`field-captions`, link `expression`, etc.) | **New scan** |
| 4 | **Parameter source field** | `source-field` attr on Parameters `column` | **New scan** |

```text
used = true  IF ANY OF:
  downstream(fieldId).length > 0
  usages(fieldId).length > 0
  actionRefs(fieldId).length > 0
  parameterSourceRefs(fieldId)        // source-field
```

## Parameter `source-field` (locked)

List parameters can take their allowed values from a datasource field. This is **not** expressed in the parameter's `calculation.formula` — it uses a dedicated attr on the parameter `column` node.

### Schema

| Attr | Parent | Format | Example |
|------|--------|--------|---------|
| `source-field` | Parameters `column` (`param-domain-type: list`) | Qualified `[datasource].[field]` | `[federated.10nnk8d1vgmw8q17yu76u06pnbcj].[Segment]` |

### Fixture: Segment Parameter

```json
{
  "type": "column",
  "attrs": {
    "name": "[Parameter 0837838388154369]",
    "caption": "Segment Parameter",
    "param-domain-type": "list",
    "value": "\"Consumer\"",
    "source-field": "[federated.10nnk8d1vgmw8q17yu76u06pnbcj].[Segment]"
  },
  "children": [
    {
      "type": "calculation",
      "attrs": { "formula": "\"Consumer\"", "class": "tableau" }
    }
  ]
}
```

- **`[Segment]`** → `used: true` (via `source-field`; also set + sheet usage in fixture).
- **Segment Parameter** → `used: false` until referenced in a calc or sheet (not in any formula yet).

### Implementation

New function in `fieldUsage.ts` (or `fieldReferences.ts`):

```text
buildParameterSourceRefs(workbook, fields) → Map<fieldId, true>
```

1. Walk `Parameters` datasource `column` children.
2. Read `attrs["source-field"]` when present.
3. Resolve via `resolveReferenceString` (qualified ref).
4. Mark resolved field ID as a parameter source.

**Not the same as downstream:** the parameter depends on the field, but M1 formula parsing does not create an edge from `[Segment]` → Segment Parameter. `source-field` is its own `used` signal.

## Architecture delta

```

  └── skip sheet_link action groups

buildFieldIndex()
  ├── … existing pipeline …
  └── computeUsed(index)
```

## Acceptance criteria

- [ ] All `sheet_link` action groups excluded from `index.fields`
- [ ] `[Segment Set]` and normal fields remain indexed
- [ ] Every `FieldRecord` has `used: boolean`
- [ ] `[Segment]` → `used: true` (includes `source-field` from Segment Parameter)
- [ ] Segment Parameter → `used: false` (no calc/sheet refs in fixture)
- [ ] At least one field asserted `used: false` in tests
- [ ] `FieldTable` shows **Used** column
- [ ] `searchFields()` never returns action groups
- [ ] Docs describe exclusion rule, `used` signals, and `source-field`
