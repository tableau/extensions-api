# M1.2 Task Brief — Field display attributes

**Status:** Done  
**Milestone:** M1.2 — between M1.1 (done) and M2  
**Last updated:** 2026-06-09

---

## Goal

Enrich `FieldRecord` with field-level display metadata from the workbook tree and surface it in the Omnisearch field table:

1. **Parameter source field** — list parameters fed by a column store the resolved source field and show it in the table.
2. **Number format** — store `default-format` from the **column definition** where present.
3. **Default aggregation** — store aggregation from the **column definition** only (e.g. **Profit per Order** → `Avg` via `visual-totals`).

---

## In scope

| Item | Description |
|------|-------------|
| **`sourceField` on parameters** | Resolve `source-field` attr → `sourceFieldId` + `sourceFieldCaption` on parameter `FieldRecord` |
| **`numberFormat` on all fields** | From column/group `attrs["default-format"]`; `null` when absent |
| **`defaultAggregation` on all fields** | From column/group attrs only (`visual-totals`); `null` when absent |
| **Table columns** | **Source field**, **Format**, **Aggregation** |
| **Null display** | When `numberFormat` or `defaultAggregation` is `null`, table shows **`default`** (Tableau implicit default) |
| **Search text** | Include source field caption and raw format string in `searchText` |
| **Tests** | Golden assertions on `workbook_export.json` |
| **Docs** | `workbook-metadata.md`, `implementation-log.md`, `tableau-poweruser-scope.md` |

---

## Out of scope

- Human-readable format translation (show raw Tableau format string when set, e.g. `p0.00%`)
- **All worksheet / sheet-level signals** — `column-instance`, shelf derivations, embedded `datasource-dependencies`
- Datasource-level `column-instance` `derivation` (not column-definition attrs)
- `metadata-record` / physical-column `aggregation` child nodes
- Search bar and facet filters (M2)
- Description / `desc` child text (defer unless needed for search)

### Default aggregation (column only)

| Attr | Parent | Example |
|------|--------|---------|
| `visual-totals` | `column` | Profit per Order → `Avg` |

**Only source.** Do not infer from `column-instance`, worksheet shelves, or any non-column node.

**Profit per Order** (canonical column under federated datasource):

```json
{
  "type": "column",
  "attrs": {
    "name": "[Sales per Customer (copy)]",
    "caption": "Profit per Order",
    "visual-totals": "Avg",
    "default-format": "p0.00%"
  },
  "children": [
    {
      "type": "calculation",
      "attrs": { "formula": "Sum([Profit])/countD([Order ID])" }
    }
  ]
}
```

**Note:** `visual-totals` appears only on this field in the current fixture. Most fields have no explicit aggregation attr → `defaultAggregation: null` → table shows **`default`**.

## `FieldRecord` delta

```typescript
export interface FieldRecord {
  // … existing fields …
  sourceFieldId: string | null;       // parameters only; resolved from source-field
  sourceFieldName: string | null;  // display helper; fieldName ?? fieldId of source
  numberFormat: string | null;        // raw default-format attr; null = Tableau default
  defaultAggregation: string | null;  // raw visual-totals attr; null = Tableau default
}
```

**Storage vs display:** `FieldRecord` keeps `null` for absent attrs. The UI maps `null` → label **`default`** for Format and Aggregation columns only.

## Implementation

### `fieldCatalog.ts`

In `fieldRecordFromNode()`:

- Read `default-format` → `numberFormat`
- Read `visual-totals` → `defaultAggregation`
- For `kind === 'parameter'`: read `source-field`, resolve via `resolveReferenceString`, set `sourceFieldId` / `sourceFieldCaption`

No secondary enrichment pass. No `column-instance` scan.

### `FieldTable.tsx`

| Column | Cell value |
|--------|------------|
| Source field | Parameter with source: `sourceFieldCaption`; else `—` |
| Format | `numberFormat ?? 'default'` |
| Aggregation | `defaultAggregation ?? 'default'` |
